Abandoned Cart Flow Manager

💡 How It Works

Automate sending cart recovery webhooks to Reply.cx. When a checkout is updated, we start a countdown. If no order is placed within that timeframe, the customer's details are sent to Reply.cx to trigger your custom messaging flow. If they purchase, the trigger is automatically suppressed!

Enable Abandoned Cart Flow When enabled, checkout updates are tracked to send recovery messages.

Enter the specific webhook URL provided by Reply.cx to trigger your abandoned cart sequence.

Optional bearer token if required by the Reply.cx webhook.

Wait time before triggering the abandoned cart message (default: 60 minutes).

Copy these webhook URLs and paste them in your Shopify settings (Settings → Notifications → Webhooks) to feed data into this flow.

1. Checkout Updated Webhook

Create a webhook for Checkout Update and paste this URL:

https://your-domain.com/api/webhook?event=checkouts/update

2. Order Created Webhook (for Suppression)

Create a webhook for Order Creation and paste this URL (if not already using the existing campaign webhook):

https://your-domain.com/api/webhook?event=orders/create
